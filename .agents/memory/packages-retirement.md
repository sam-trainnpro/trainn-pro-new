---
name: Packages browse retirement
description: Product rationale and scope for retiring the public packages listing.
---

The public packages browse page should stay removed unless explicitly requested otherwise. This does not mean removing provider package management or package purchasing elsewhere.

**Why:** The user said the page did not look high quality enough and people were not using it.

**How to apply:** Do not reintroduce public packages navigation when working on package-related features; preserve existing package functionality outside the retired listing.
